# ⏱️ JavaScript Stopwatch

A sleek, lightweight, and fully functional stopwatch web application built with **HTML5**, **CSS3**, and **Vanilla JavaScript**. 

## ✨ Features

- **Start, Stop & Reset:** Full control over your time tracking with intuitive action buttons.
- **Toggle Pause:** Click the start/play button a second time to pause the timer without losing your place.
- **Zero-Padded Display:** Automatically formats hours, minutes, and seconds into a clean `HH:MM:SS` layout (e.g., `00:05:09`).
- **Bug-Free Interval Management:** Properly clears timers and manages states to prevent speed-doubling bugs.

## 🛠️ Built With

- **HTML5** – Structure and DOM layout
- **CSS3** – Styling and iconography layout
- **JavaScript (ES6)** – Stopwatch logic, array/interval handling, and DOM manipulation
